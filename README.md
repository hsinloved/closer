# Closer

A card game for two — questions to get to know each other, play, and go deeper.

**Modes**
- **Free play** — pick any level, any time.
- **Journey** — go level by level (Know → Play → Worlds → Deeper), then a final card for you both.

**Levels:** Know · Play · Worlds (Taiwan meets Germany) · Deeper · Mix, plus wild cards.

Progress, names and saved cards are stored in your browser.

## Play online (GitHub Pages)
1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**, branch `main`, folder `/ (root)` → Save
3. Open `https://<your-username>.github.io/<repo-name>/` after ~1 minute.
